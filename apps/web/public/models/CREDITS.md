# 3D asset credits

The office furniture and character models under `public/models/` are CC0
(public domain) assets, mirrored via
https://github.com/beep2bleep/FreeAssetsByKenneyNLandQuaternius

- **Furniture** (`models/furniture/*.glb`): Kenney.nl — "Furniture Kit".
  https://kenney.nl — originally shipped as ASCII FBX, converted to .glb
  with `assimp` because three.js's FBXLoader fails to parse this pack's
  ASCII FBX export (fails identically on every file in it).
- **Characters** (`models/characters/*.fbx`): Quaternius — "Animated Men /
  Animated Women" character packs (rigged, with Idle/Walk/Sitting/Run
  animation clips baked in). https://quaternius.com

Both sources are released under CC0: free to use, modify, and redistribute
commercially with no attribution required. This file is kept anyway as
good practice.
